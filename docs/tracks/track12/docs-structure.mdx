# Documentation Site Structure

This document explains the navigation structure and organization of the Athletic Academics Hub documentation site.

## Overview

The documentation site is built with Nextra and organized around 12 parallel development tracks, plus operational and contribution documentation.

## Navigation Configuration

The navigation is configured in `theme.config.jsx`:

```javascript
export default {
  logo: <span>Athletic Academics Hub</span>,
  project: {
    link: "https://github.com/your-org/athletic-academics-hub",
  },
  docsRepositoryBase:
    "https://github.com/your-org/athletic-academics-hub/blob/main/docs",
  useNextSeoProps() {
    return {
      titleTemplate: "%s | AAH Docs",
    };
  },
  footer: {
    text: "Athletic Academics Hub Documentation",
  },
  toc: {
    backToTop: true,
    extraContent: (
      <>
        <Callout type="info">
          Need help? Check our{" "}
          <a href="https://github.com/your-org/athletic-academics-hub/issues">
            GitHub Issues
          </a>
        </Callout>
      </>
    ),
  },
};
```

## Track Metadata

Each track has a `_meta.mdx` file that defines its navigation structure:

```javascript
{
  "index": "Overview",
  "filename": "Display Name"
}
```

## Adding New Documentation

### Adding a New Page

1. Create a new `.mdx` file in the appropriate track directory
2. Add an entry to the track's `_meta.mdx` file
3. Write the content in Markdown with React components

### Creating a New Track

1. Create a new track directory: `docs/trackXX/`
2. Add `_meta.mdx` with navigation configuration
3. Create `index.mdx` with track overview
4. Add track to main `index.mdx` if needed

## Custom Components

The documentation supports these Nextra components:

- `Callout` - Information boxes (info, warning, error)
- `Tabs` - Tabbed content
- `Cards` - Card layouts
- `Steps` - Step-by-step guides
- Code blocks with syntax highlighting
- Inline components via MDX

## Best Practices

<Callout type="info">
  **Documentation Guidelines**

- Use clear, descriptive titles
- Include code examples with syntax highlighting
- Add visual aids (diagrams, screenshots)
- Keep content focused and scannable
- Link to related documents
- Update content as code changes
  </Callout>

## Deployment

The documentation is deployed to Vercel:

1. Connected to Vercel via GitHub integration
2. Automatic deployment on push to `main`
3. Preview deployments for PRs
4. Custom domain: `docs.athletic-academics-hub.com`
