## Migration Guides

### Migrating from v1 to v2

#### Button Component

**v1:**

```tsx
<Button primary size="large">
  Click me
</Button>
```

**v2:**

```tsx
<Button variant="primary" size="lg">
  Click me
</Button>
```

#### Input Component

**v1:**

```tsx
<Input type="text" placeholder="Enter text" />
```

**v2:**

```tsx
<Input type="text" placeholder="Enter text" />
```

#### Theme System

**v1:**

```tsx
import { theme } from "@packages/ui/theme";
<Button theme={theme.primary}>Click</Button>;
```

**v2:**

```tsx
<Button variant="primary">Click</Button>
```

## Deprecation Policy

- Components are deprecated for at least 6 months before removal
- Deprecated components are marked in documentation
- Migration guides are provided for all major changes
- Breaking changes are reserved for major versions
