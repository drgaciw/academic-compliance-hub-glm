## Notes for New Team Members

1. **Keep it brief**: Focus on key accomplishments and blockers
2. **Be specific**: When mentioning blockers, include owner and expected resolution
3. **Use @mentions**: Tag team members when you need their attention
4. **Link to PRs/issues**: Reference specific GitHub issues or pull requests
5. **Track percentages**: Use realistic progress estimates
6. **Blockers are important**: Don't hide blockers - that's how we help each other

## Live Standup Format (Optional for Critical Sprints)

When the team prefers a live standup (e.g., during critical sprints or when multiple blockers exist):

### Schedule

- **Time**: Daily at 10:00 AM EST
- **Duration**: Max 15 minutes total
- **Platform**: Zoom / Google Meet / Discord Voice

### Format

1. Each person gets 2 minutes
2. Go through the same 4 questions as above
3. Post blockers in chat after standup for documentation
4. Record summary in `#standup` channel

### Attendees

- Required: All track leads
- Optional: Team members with blockers or announcements
