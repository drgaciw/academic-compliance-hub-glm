# @aah/main

Main web application for the Athletic Academics Hub (AAH).

## Overview

This is the primary Next.js application that serves as the main interface for:
- Student athletes
- Academic advisors
- Compliance officers
- Administrators

## Tech Stack

- **Framework**: Next.js 14 with App Router
- **UI**: React 18 with Shadcn/UI components
- **Auth**: Clerk integration via @aah/auth
- **Database**: Prisma via @aah/database
- **AI**: Vercel AI SDK via @aah/ai

## Development

```bash
# Install dependencies
pnpm install

# Run development server
pnpm dev

# Build for production
pnpm build

# Start production server
pnpm start
```

## Features

- NCAA Division I compliance tracking
- Academic progress monitoring
- Course advising system
- AI-powered insights and recommendations
- Real-time notifications and alerts
