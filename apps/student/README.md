# @aah/student

Student portal for the Athletic Academics Hub (AAH).

## Overview

This is a dedicated Next.js application for student athletes to:
- View academic progress and eligibility
- Access course schedules and assignments
- Request tutoring and support services
- Communicate with academic advisors
- Track NCAA compliance requirements
